Analytics — Setup Required

The GA4 Data API credentials are not configured on this server, so the dashboard can't read your analytics yet. Add the four environment variables below, then reload.

  1. GA_PROPERTY_ID — the numeric GA4 Property ID
  2. GA_OAUTH_CLIENT_ID
  3. GA_OAUTH_CLIENT_SECRET
  4. GA_OAUTH_REFRESH_TOKEN

To generate the OAuth values, run this once locally and paste the output into the server's environment variables:

python manage.py ga_capture_token /path/to/oauth-client.json

Then confirm the credentials work with:

python manage.py ga_verify
